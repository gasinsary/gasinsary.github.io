# Brief 2 : campagne publicitaire déclinée pour Bao Fizz (projet concept)

Page du site : `/portfolio/campagne-publicitaire-bao-fizz/`
Fiche à compléter ensuite : `_projets/campagne-publicitaire-bao-fizz.md`
Temps visé : une journée.

## Pourquoi ce projet

Le cœur de métier de Digital Prod est la déclinaison : un visuel de campagne adapté proprement à tous les formats (bannières, e-mailing, réseaux sociaux). Ce projet montre que vous savez garder un message lisible dans un format très large, très étroit ou très petit.

## La marque (fictive)

- **Nom** : Bao Fizz. Vérifié rapidement : pas de marque trouvée sous ce nom, mais ce n'est pas une recherche de dépôt de marque. Le nom peut être changé.
- **Produit** : boisson pétillante au fruit du baobab, en canette de 33 cl. Trois parfums : citron vert, mangue, hibiscus.
- **Cible** : 18 à 30 ans.
- **Ton** : énergique, joyeux, direct.
- **Campagne** : lancement d'été. Accroche : « L'été a du peps. » Offre : « -20 % sur le pack découverte ». Bouton : « J'en profite ».

## Mini-charte proposée

Vous restez libre de l'ajuster.

| Couleur | Code | Usage |
|---|---|---|
| Jaune soleil | `#FFC629` | Fond principal |
| Corail | `#FF5A4E` | Accent, bouton |
| Vert citron | `#9BD63F` | Parfum citron vert, détails |
| Bleu nuit | `#14213D` | Textes |
| Blanc | `#FFFFFF` | Respirations |

- **Titres** : Archivo Black ou Bricolage Grotesque (Google Fonts, gratuites).
- **Textes** : Inter (Google Fonts, gratuite).
- **Images** : maquette de canette (dessinée ou libre de droits), fruits, éclaboussures. Notez les sources utilisées.

## Ce qu'il faut créer

| # | Format | Dimensions | Remarque |
|---|---|---|---|
| 1 | Visuel principal | 1920 × 1080 px | La référence dont tout le reste découle |
| 2 | Pavé | 300 × 250 px | Le format le plus diffusé |
| 3 | Bannière | 728 × 90 px | Très large et très bas : une seule ligne de texte |
| 4 | Skyscraper | 160 × 600 px | Très étroit : empiler logo, produit, accroche, bouton |
| 5 | Demi-page | 300 × 600 px | Le plus confortable des formats verticaux |
| 6 | En-tête de newsletter | 1200 × 600 px (affiché à 600 px de large) | Accroche, produit, offre, bouton |

Contraintes des bannières :
- Chaque bannière contient le logo, l'accroche, le produit et le bouton.
- Un filet de 1 px autour de chaque bannière (exigence des régies publicitaires).
- Chaque fichier exporté pèse moins de 150 Ko.
- Le bouton garde la même couleur et la même forme partout.

## Ce qu'il faut me remettre pour la page du site

Cinq images à déposer dans `portfolio/campagne-publicitaire-bao-fizz/img/`, **en gardant exactement ces noms** (elles remplacent les images provisoires) :

| Fichier | Contenu |
|---|---|
| `couverture.webp` | Le visuel principal recadré, pour la carte du portfolio |
| `planche-1.webp` | Le visuel principal |
| `planche-2.webp` | Les quatre bannières réunies sur une planche, à l'échelle |
| `planche-3.webp` | Une bannière en situation, dans une maquette de page web |
| `planche-4.webp` | L'en-tête de newsletter en situation, dans une maquette de messagerie |

Format de chaque image : WebP, 1024 × 683 px, moins de 150 Ko.

## Ce que l'agence regardera

- Le message reste complet et lisible dans le format le plus contraint (728 × 90 et 160 × 600).
- La marque est reconnaissable d'un format à l'autre.
- Le bouton est toujours visible et cohérent.
- La propreté d'exécution : alignements, marges, netteté à l'export.

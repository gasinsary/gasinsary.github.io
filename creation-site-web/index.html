Création de site web et d'application

Site vitrine, site sur mesure, application web ou mobile, boutique en ligne, refonte : Gas'in Sary, studio créatif francophone basé à Madagascar, conçoit et développe votre site à distance, pour les entreprises et les agences en France et à l'international. Un site rapide, lisible sur téléphone, pensé pour le référencement, et qui vous appartient.

Ce que nous créons

Du site d'une page à l'application complète, dans la continuité de votre identité visuelle.

Site vitrine

Présenter votre entreprise, vos services et vos réalisations, et donner envie de vous contacter. Les pages qu'il faut, bien écrites, bien référencées.

Site sur mesure

Quand un modèle ne suffit pas : un site dessiné pour vous, avec les fonctions dont vous avez besoin, et rien d'autre.

Application web

Un outil de gestion, un espace client, un tableau de bord : une application accessible depuis un navigateur, sur ordinateur comme sur téléphone.

Application mobile

Une application pensée pour le téléphone, pour vos clients ou pour vos équipes, en prolongement de votre site ou de votre outil.

Boutique en ligne

Catalogue, panier, commande et paiement : une boutique claire, rapide, et simple à administrer au quotidien.

Refonte de site

Votre site a vieilli, se lit mal sur téléphone ou n'apparaît plus dans Google ? Nous repartons de ce qui fonctionne et refaisons le reste, sans perdre vos adresses déjà référencées.

Ce que vous recevez

Les cinq points que nos clients nous demandent avant de signer, et qui sont compris dans chaque projet.

Un site lisible sur téléphone

Plus de la moitié de vos visiteurs viennent d'un mobile. Chaque page est conçue d'abord pour l'écran du téléphone, puis pour l'ordinateur.

Des pages rapides

Images compressées, code léger, pas de script inutile. Un site qui s'affiche vite garde ses visiteurs et plaît à Google.

Un site prêt pour le référencement

Contenu lisible par les moteurs de recherche, un titre et une description par page, plan du site, adresses propres. Les bases du référencement sont posées dès la mise en ligne.

Une connexion sécurisée

Le site est servi en https, avec les bonnes pratiques de sécurité de la technologie retenue, et des accès que vous contrôlez.

Un site qui vous appartient

Le nom de domaine, l'hébergement et les comptes sont ouverts à votre nom. Vous en restez propriétaire ; nous y gardons un accès technique pour la mise en place et le suivi.

Le code et les fichiers

À la livraison, vous recevez le code source du site, les maquettes et les images. Vous pouvez le faire évoluer avec nous ou avec un autre prestataire.

Les technologies que nous utilisons

Nous choisissons la technologie d'après le projet, pas l'inverse. Un site vitrine n'a pas besoin de l'outillage d'une application.

Pour les sites

HTML, CSS et JavaScript pour les sites vitrines : des pages légères, rapides et faciles à référencer, hébergées à peu de frais. PHP et MySQL quand le site a besoin d'un espace d'administration, de formulaires avancés ou d'un catalogue.

Pour les applications

React et Next.js pour les applications web et les sites sur mesure, avec une base de données PostgreSQL ou MySQL. C'est la technologie de Voolapp, l'application de gestion que nous avons conçue et développée.

Intégration d'intelligence artificielle

Un assistant qui répond à vos clients, une recherche qui comprend les questions, une aide à la rédaction ou au classement : nous intégrons ces fonctions dans votre site ou votre application à partir des services d'IA existants, quand elles ont un usage réel.

Et l'identité visuelle

Un site reprend votre logo, vos couleurs et vos typographies. Si vous n'en avez pas encore, nous créons d'abord votre logo et votre identité visuelle, puis le site dans la continuité.

Comment se passe un projet

Tout se fait à distance, par e-mail, sur WhatsApp ou en visio, avec un seul interlocuteur du début à la fin.

1. Le besoin et le devis

Vous décrivez votre projet : à qui il s'adresse, ce qu'il doit faire, ce que vous avez déjà. Nous revenons avec des questions précises, puis un devis qui liste ce qui sera livré.

2. Les maquettes

Nous dessinons les pages principales et vous les validez avant la première ligne de code. Si vous avez déjà des maquettes, nous partons des vôtres.

3. Le développement

Le site prend forme sur une adresse de test que vous consultez à tout moment. Vos retours sont intégrés étape par étape.

4. La mise en ligne

Nous installons le site sur votre nom de domaine et votre hébergement, le déclarons aux moteurs de recherche et vous remettons le code et les accès.

Hébergement, nom de domaine et maintenance

Le nom de domaine, l'hébergement et les services nécessaires au site sont souscrits par vous, à votre nom : ils vous appartiennent, et vous recevez leurs factures directement. Nous vous indiquons quoi prendre, nous mettons tout en place, et nous gardons un accès technique. Dès le devis, vous connaissez ces frais, qui s'ajoutent à notre prestation.

Après la mise en ligne, nous pouvons assurer la maintenance : mises à jour, sauvegardes, petites évolutions. Son contenu et son rythme se définissent avec vous, selon le site et vos besoins.

Questions fréquentes

Combien coûte un site web ?

Cela dépend de ce qu'il faut créer : un site vitrine de quelques pages, une boutique ou une application n'ont pas le même prix. Décrivez-nous votre projet, nous vous envoyons un devis détaillé, avec les frais d'hébergement et de domaine à prévoir en plus.

Combien de temps prend un projet ?

Le délai dépend de la taille du site et de la rapidité de vos retours. Il est fixé dans le devis, avec un calendrier par étape.

À qui appartient le site ?

À vous. Le nom de domaine et l'hébergement sont à votre nom, et vous recevez le code source. Vous pouvez changer de prestataire sans rien perdre.

Pourrai-je modifier le site moi-même ?

Si vous souhaitez mettre à jour vos textes ou vos produits sans passer par nous, nous le prévoyons dès le devis et choisissons la solution en conséquence.

Peut-on vraiment travailler à distance ?

Oui, c'est notre façon habituelle de travailler. Madagascar n'a qu'une à deux heures de décalage avec Paris, et tous les échanges se font en français.
